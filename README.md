# ATM Simulation System (Java)

## 📌 Project Overview
This project is a **console-based ATM Simulation System** developed in **Java** as part of my internship.  
It simulates basic ATM functionalities using object-oriented programming concepts.

## ✨ Features
- PIN verification for secure access
- Balance inquiry
- Cash withdrawal
- Cash deposit
- Menu-driven user interface
- Session handling and input validation

## 🛠️ Technologies Used
- Java
- OOP Concepts
- Command Line Interface (CLI)
